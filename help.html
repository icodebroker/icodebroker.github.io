도움말

받아서 실행하기

  1. 원하는 프로그램의 무료 다운로드 버튼을 눌러 zip 파일을 받아요.
  2. zip 파일을 오른쪽 클릭 → 압축 풀기를 눌러 원하는 폴더에 풀어요.
  3. 폴더 안의 .exe 파일을 두 번 클릭하면 바로 실행돼요. 설치 과정은 없어요.

Windows 10 또는 11 64비트에서 돌아가요. .NET 같은 다른 프로그램을 따로 설치할 필요가 없어요.

"Windows의 PC 보호" 창이 떠요

이 프로그램들은 유료 코드 서명 인증서 없이 배포해서, 처음 실행할 때 Windows SmartScreen이 경고할 수 있어요.

  1. 창에서 추가 정보를 눌러요.
  2. 아래에 생긴 실행 버튼을 눌러요.

한 번 실행하면 다음부터는 뜨지 않아요. 걱정되면 아래 방법으로 파일이 온전한지 먼저 확인하세요.

파일이 온전한지 확인하기

각 프로그램 소개 페이지의 자세한 정보에 zip 파일의 SHA-256 값이 있어요. PowerShell에서 받은 파일이 있는 폴더로 가서 아래처럼 입력하고, 나온 값이 페이지의 값과 같은지 보세요.

Get-FileHash .\BigEdit-1.0.0-win-x64.zip

백신이 막아요

설치 없이 실행되는 단일 exe 파일은 일부 백신이 잘못 진단하는 경우가 있어요. 이 사이트(GitHub)에서 직접 받은 파일이고 SHA-256 값이 같다면 백신의 예외 목록에 추가해서 쓰시면 돼요.

지우는 법

설치하지 않으니 exe 파일과 압축 푼 폴더를 지우면 끝이에요. 설정과 기록까지 지우려면 프로그램을 닫고, 소개 페이지의 자세한 정보 → 저장되는 파일에 적힌 파일과 폴더도 지우세요. 프로그램이 파일을 만드는 곳은 주로 이렇습니다.

  • exe 옆 CONFIGURATION 폴더 : 대부분의 프로그램이 설정을 여기에 저장해요. exe 폴더를 통째로 옮기면 설정도 함께 옮겨져요.
  • %APPDATA%, %LOCALAPPDATA%의 프로그램 이름 폴더 : 일부 프로그램의 설정과 메모·기록 데이터베이스, 캐시, 작업 기록이 여기에 있어요. 탐색기 주소 표시줄에 %LOCALAPPDATA%처럼 그대로 입력하면 열려요.
  • %TEMP%\.net\프로그램 이름 : 실행할 때 .NET이 풀어 두는 DLL이에요. 프로그램을 닫은 뒤 지워도 다음 실행 때 다시 만들어져요.

메모, 일정, 클립보드 기록, 등록한 서버처럼 직접 만든 데이터가 든 파일은 지우면 되돌릴 수 없으니 필요하면 먼저 복사해 두세요. 암호와 인증키는 Windows 사용자 계정으로 암호화해 두는 경우가 많아서, 다른 PC로 옮기면 다시 넣어야 해요. 시작 프로그램이나 탐색기 메뉴처럼 레지스트리에 등록하는 프로그램(BigReader, BigZIP 등)은 exe를 지우기 전에 프로그램에서 그 옵션을 끄거나 등록을 해제하세요.

관리자 권한이 필요한 프로그램

BigDisk, BigPacket처럼 시스템 정보를 읽는 몇몇 프로그램은 실행할 때 관리자 권한을 물어요. 각 소개 페이지에 적어 두었어요.
