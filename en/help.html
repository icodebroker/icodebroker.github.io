Help

Download and run

  1. Click the Free download button of the app you want to get the zip file.
  2. Right-click the zip file → Extract All and pick a folder.
  3. Double-click the .exe file in that folder. There is no installer.

Runs on Windows 10 or 11 (64-bit). You don't need to install .NET or anything else.

"Windows protected your PC" appears

These apps are shared without a paid code-signing certificate, so Windows SmartScreen may warn you the first time you run one.

  1. Click More info.
  2. Click the Run anyway button that appears.

It won't show up again for that file. If you'd like, check the file first as shown below.

Check that the file is intact

Each app page lists the zip file's SHA-256 under More details. In PowerShell, go to the folder with the downloaded file, run the command below and compare the result with the page.

Get-FileHash .\BigEdit-1.0.0-win-x64.zip

My antivirus blocks it

Some antivirus products wrongly flag single-file portable exes. If you downloaded it from this site (GitHub) and the SHA-256 matches, you can add it to your antivirus exceptions.

How to remove

Nothing is installed, so just delete the exe and the extracted folder. To remove settings and history too, close the app and delete the files and folders listed under More details → Files it creates on the app page. Apps mostly create files in these places:

  • The CONFIGURATION folder next to the exe: most apps keep their settings here. Moving the whole exe folder moves the settings with it.
  • A folder named after the app in %APPDATA% or %LOCALAPPDATA%: some apps keep settings, note or history databases, caches and journals here. Type %LOCALAPPDATA% into the File Explorer address bar to open it.
  • %TEMP%\.net\app name: DLLs that .NET unpacks when the app runs. You can delete it after closing the app; it is created again on the next run.

Files that hold data you created, such as notes, memos, clipboard history or saved servers, cannot be recovered once deleted, so copy them first if you need them. Passwords and keys are often encrypted with your Windows account, so they must be entered again on another PC. For apps that register in the registry, such as start-up entries or Explorer menus (BigReader, BigZIP and others), turn the option off or unregister in the app before deleting the exe.

Apps that need administrator rights

A few apps that read system information, such as BigDisk and BigPacket, ask for administrator rights when they start. Their pages mention it.
